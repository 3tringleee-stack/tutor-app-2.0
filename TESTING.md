# Проверочные сценарии

Список случаев, в которых чаще всего ломается учёт денег. Каждый прогоняется автоматически: `node tests.js` рядом с `index.html`.

## Что проверяется

| № | Сценарий | Что должно получиться |
|---|---|---|
| 1 | Занятие из сентября перенесено на октябрь и проведено | Деньги считаются в октябре, сентябрь остаётся нулевым |
| 2 | Цена поднята с 1 октября | Сентябрьские занятия остаются по старой ставке |
| 3 | Пробное занятие | Числится проведённым, стоит 0 ₽, баланс не меняется |
| 4 | Разовый ученик без расписания | Занятие считается, план по расписанию пуст, предупреждений нет |
| 5 | Пара: отмена с оплатой | У каждого списывается по своей ставке |
| 6 | Группа: один отменил | У двоих списано, у третьего нет |
| 7 | Снятие отметки (↺) | Баланс возвращается, занятие снова «не отмечено» |
| 8 | Правка длительности до отметки (✎) | Занятие дорожает пропорционально часам |
| 9 | Сверка оплат и реестр | Статус «оплачено», строка «Итого» совпадает с суммой строк |
| 10 | Выгрузка Excel | Файл формируется и открывается без ошибок |
| 11 | День отчёта 1-го числа | Отчёт готовится за прошлый месяц |

## Как запускать

```
node tests.js
```

Нужен Node.js. Тесты работают прямо с логикой из `index.html`: скрипт вынимается из файла и подключается с заглушкой браузера (`test-dom.js`). Если какая-то проверка падает, в выводе видно, что получено и что ожидалось.

## Ручные проверки, которые автоматика не заменит

- Открыть все четыре вкладки на телефоне и на компьютере — не разъехалась ли вёрстка.
- Закрыть месяц и сверить итог с реальными деньгами.
- Дать приложение человеку, который его не видел, и молча смотреть, где он остановится.

| 12 | Занятие 45 минут, отчёт родителю с датами и заметками | 45 мин = 0,75 ставки; в тексте «• 06.10, 45 мин — дроби», даты по порядку |
| 13 | Сверка с учётом прошлых месяцев | аванс из сентября и оплата месяца вперёд не делают ученика должником; долг за сентябрь добавляется к октябрю; в реестре колонка «С прошлого месяца» |

## Синхронизация с Telegram

`node tests-sync.js` — пять сценариев на поддельном облаке: новый пользователь видит пустой экран; сбой чтения не перезаписывает облако; разовый сбой лечится повторной попыткой; записи с устройства переносятся в пустое облако; при возврате в приложение видны отметки с другого устройства.

## Сквозной тест в браузере

`node tests-e2e.js` открывает приложение в чистом браузере размером с телефон (390×820) и проходит его целиком, как человек. Ваши настоящие данные не затрагиваются.

| № | Что проходит | Что проверяет |
|---|---|---|
| 1 | Первый запуск | пустой экран с мастером, нет чужих учеников, нет мусора в разметке |
| 2 | Мастер ученика | имя, день, 45 минут, цена, способ оплаты, родитель |
| 3 | Отметка | «Проведено» списывает 1 200 ₽, заметка «что прошли», снятие отметки |
| 4 | Правка до отметки | нажатие на время, новая длительность меняет сумму |
| 5 | «Не было» | перенос с датой, без даты, отмена с оплатой и без, каникулы |
| 6 | Деньги | оплата гасит долг, пробное бесплатно, доп. занятие |
| 7 | Разовые и группы | разовый ученик, группа из 3 человек одной строкой |
| 8 | Календарь | листание месяцев, «месяц в цифрах» |
| 9 | Отчёт | текст родителю с датами и заметками, сверка, реестр, настоящий .xlsx |
| 10 | Карточка | история, смена цены с даты без пересчёта прошлого, архив |
| 10б | Расписание | новый день со своим временем и длительностью, смена времени с даты без пересчёта прошлого, нельзя сохранить без времени, «каждую неделю» ставит разовое занятие на постоянку |
| 11 | Свободные окна | подбор времени и текст для родителя |
| 12 | Настройки | нет удалённых настроек, темы и тёмный режим |
| 13 | Копия | скачать, потерять данные, восстановить |
| 14 | Импорт | расписание текстом |
| 15 | Телефон | сохранение после перезагрузки, нет горизонтальной прокрутки, кнопки окна видны, с открытой клавиатурой можно дописать последнее поле |
| 16 | Новичок | подсказка «Как вести учёт» сама отмечает шаги и исчезает, «Показать снова», пробный режим `?new` не трогает данные |
| 17 | Ошибки | ни одной ошибки JavaScript за весь проход |

Если что-то сломалось, рядом появится `proverka-oshibka.png` — снимок экрана в момент ошибки.

## Что тест проверить не может

Только руками в Telegram на телефоне: кнопка «Назад» вверху окна, синхронизация между телефоном и компьютером, подтверждение при закрытии с открытой формой.
