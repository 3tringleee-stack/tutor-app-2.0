# Бот «Табеля»

Отвечает на /start приветствием с кнопкой «Открыть Табель», на /help — короткой инструкцией, на любой другой текст — подсказкой. Ничего не хранит: ни учеников, ни сообщений.

Работает на Cloudflare Workers, бесплатный тариф: 100 000 запросов в день.

## Как запустить (≈20 минут, один раз)

1. **Регистрация.** dash.cloudflare.com → Sign up (почта и пароль, карта не нужна).
2. **Создать воркер.** Слева «Workers & Pages» → «Create» → «Create Worker» → имя `tabel-bot` → «Deploy».
3. **Вставить код.** «Edit code» → удалить всё в окне → вставить содержимое `worker.js` → «Deploy».
4. **Настройки.** Назад к воркеру → «Settings» → «Variables and Secrets» → «Add»:

   | Имя | Тип | Значение |
   |---|---|---|
   | `BOT_TOKEN` | Secret | токен @tabelapp_bot из @BotFather |
   | `APP_URL` | Text | адрес **сайта** на GitHub Pages: `https://ваш-ник.github.io/репозиторий/` (не `github.com/…`) |
   | `WEBHOOK_SECRET` | Secret | любая строка из латиницы и цифр, 20+ символов, например `tabel_2026_k7m3q9x4p2` |
   | `AUTHOR_TG` | Text | ваш ник без @ (необязательно) |

   → «Deploy».
5. **Подключить бота.** Открыть в браузере один раз:
   `https://tabel-bot.<ваш-поддомен>.workers.dev/setup?key=<WEBHOOK_SECRET>`
   Адрес воркера виден на его странице. Должно появиться «Готово: бот подключён».
6. **Проверить.** Написать боту `/start`.

## Если что-то не так

- **«Нет доступа»** — ключ в адресе не совпадает с `WEBHOOK_SECRET`.
- **«Открыть Табель» открывает GitHub, а не приложение** — в `APP_URL` стоит адрес репозитория. Нужен адрес сайта: GitHub → репозиторий → Settings → Pages → «Your site is live at …». Поменяйте `APP_URL` → «Deploy». Повторять настройку не нужно.
- **«Не заданы BOT_TOKEN или APP_URL»** — не добавлена переменная или забыли нажать «Deploy» после добавления.
- **Страница настройки не открывается** — адреса `*.workers.dev` иногда недоступны у российских провайдеров. Откройте этот шаг через VPN, сам бот после подключения работает без него: сообщения ему шлют серверы Telegram, а не ваш браузер.
- **Бот молчит** — в @BotFather не должно быть других вебхуков; повторите шаг 5.
- **Токен засветился** — @BotFather → `/revoke`, новый токен вставить в `BOT_TOKEN` и повторить шаг 5.

## Проверка без Telegram

```
cd bot
node test-worker.mjs
```

12 проверок: приветствие, кнопка, /help, ответ на любой текст, молчание в группах, защита от чужих запросов, настройка.
