# Табель

**Учёт занятий и оплат для репетитора.**

Календарь занятий, переносы и отмены, почасовой учёт денег и отчёт за месяц. Работает как мини-приложение в Telegram и как обычная веб-страница. Серверная часть не требуется: данные хранятся в облаке Telegram и дублируются в браузере пользователя.

**Попробовать:** [@Tutor_tutorr_bot](https://t.me/Tutor_tutorr_bot) → кнопка меню.

![Табель](logo.svg)

## Зачем

Большинство репетиторов ведут учёт в тетради, заметках или таблице. Проблемы начинаются не с расписания, а с денег: перенесли занятие, отменили за час до начала, кто-то платит за месяц вперёд, кто-то после каждого урока, у всех разные ставки. В итоге в конце месяца непонятно, сколько с кого брать.

«Табель» написан практикующим репетитором для решения именно этой задачи. Название отсылает и к школьному табелю, и к табелю учёта — тому, что приложение и делает.

## Возможности

- Расписание по дням недели с временем и длительностью, история изменений расписания
- Почасовые ставки, изменение цены с выбранной даты
- Отметка занятия в два нажатия: проведено или не состоялось
- Не состоялось — это четыре разных случая: перенос с датой, перенос без даты, отмена с оплатой, отмена без оплаты, а также каникулы
- Перенос выбором дня прямо в календаре
- Парные занятия: два ученика в одной строке, у каждого свой баланс
- Баланс по каждому ученику: долг или аванс, шкала «оплачено вперёд по такое-то число»
- Отчёт за месяц с суммой к оплате и готовым текстом для родителей
- Сводка за год: часы, заработано, получено
- Экспорт в CSV для Excel, резервная копия и восстановление
- Импорт расписания текстом
- Группы и парные занятия: одна строка в расписании, отдельный баланс у каждого
- Сверка оплат за месяц и реестр для бухгалтерии
- Выгрузка в настоящий .xlsx с форматированием
- Разовые ученики и бесплатные пробные занятия
- Шаблоны сообщений родителям и подбор свободных окон
- Напоминание отметить занятия (пока работает, только когда приложение открыто)

## Как устроено

Один самодостаточный HTML-файл без сборки и зависимостей: разметка, стили и логика внутри `index.html`.

Хранилище выбирается автоматически:

| Где открыто | Хранилище |
|---|---|
| Мини-приложение Telegram | Telegram CloudStorage, синхронизация между устройствами одного пользователя, плюс копия в localStorage |
| Обычный браузер | localStorage |

Данные пользователей нигде не собираются: у проекта нет сервера и нет доступа к записям. Всё лежит в аккаунте Telegram пользователя и в его браузере.

## Проверка

Три уровня тестов:

| Команда | Что проверяет | Нужно установить |
|---|---|---|
| `node tests.js` | 34 проверки расчётов денег: переносы между месяцами, смена цены, группы, пары, пробные, реестр, Excel | ничего |
| `node tests-sync.js` | 5 сценариев синхронизации с облаком Telegram: сбой связи, перенос данных, второе устройство | ничего |
| `node tests-e2e.js` | 56 проверок в настоящем браузере на экране телефона: тест сам проходит все функции приложения | Playwright, один раз |

Установка для сквозного теста: `npm install && npx playwright install chromium`.
Посмотреть, как тест кликает: `node tests-e2e.js --show`. Подробности — в [TESTING.md](TESTING.md).

## Запуск

Локально: скачать `index.html` и открыть в браузере.

Как мини-приложение Telegram:

1. Выложить `index.html` на любой статический хостинг с HTTPS (GitHub Pages, Cloudflare Pages, Netlify).
2. Создать бота через [@BotFather](https://t.me/BotFather).
3. Bot Settings → Menu Button → Configure menu button → указать адрес страницы и название кнопки.

## Структура данных

Ученик хранит расписание периодами (`sched`), историю цен (`prices`), способ оплаты и пару. Занятия и оплаты хранятся событиями по месяцам: `lesson`, `payment`, `cancel`, `moved`, `makeup`, `skip`. Стоимость фиксируется в событии на момент проведения, поэтому изменение цены не пересчитывает прошлое.

## Планы

- Сервер и аккаунты: синхронизация без привязки к Telegram
- Бот с напоминаниями и отметкой занятий из чата
- Страница для родителя: история занятий и сумма к оплате по ссылке
- Помощь самозанятым с учётом поступлений
